# Website Conversion Checklist

Purpose: make lippytmai.getbizfunds.com easier to understand, easier to trust, and more effective at turning visitors into leads, affiliate clicks, consultations, and customers.

## Page-level checklist

For every important page:

- [ ] One clear audience.
- [ ] One clear problem.
- [ ] One clear promise.
- [ ] One primary CTA.
- [ ] Mobile-readable design.
- [ ] Fast enough to load smoothly.
- [ ] Contact or lead capture option.
- [ ] Trust/proof section.
- [ ] Affiliate disclosure when needed.
- [ ] No-guarantee disclaimer when discussing funding, income, approval, tax, legal, or investment topics.

## Homepage checklist

### Hero section

- [ ] Headline explains the brand in plain language.
- [ ] Subheadline explains the outcome.
- [ ] Primary CTA is visible without scrolling.
- [ ] Secondary CTA is optional and not distracting.
- [ ] Canva hero image supports the message.
- [ ] Text is readable on phone.

Recommended hero:

```text
Ready for Anything Business of Businesses
Funding, AI automation, creative marketing, and business systems from startup to seasoned business owner.
```

### Lead magnet section

- [ ] Free checklist is easy to understand.
- [ ] Form is short.
- [ ] Visitor knows what they get.
- [ ] Follow-up path is ready.
- [ ] Thank-you message gives next step.

### Offer cards

- [ ] Startup Readiness Kit.
- [ ] Business Growth Automation Kit.
- [ ] AI Bot Builder Package.
- [ ] Innovation Partner Deck + Roadmap.

Each card should include:

- Who it is for.
- What it helps with.
- What is included.
- CTA.

### Tools section

- [ ] Canva.
- [ ] GitHub.
- [ ] ChatGPT.
- [ ] ManyChat.
- [ ] BotBuilders.
- [ ] Twin.so.
- [ ] Replit.
- [ ] Website funnel.

### Trust/proof section

Use real proof:

- [ ] GitHub project progress.
- [ ] Canva asset examples.
- [ ] Website screenshots.
- [ ] Bot flow previews.
- [ ] Honest project updates.
- [ ] Testimonials only when real.

## CTA checklist

Good CTA examples:

- Get the Free Checklist.
- Build Your Business Money Engine.
- Request a Business Systems Review.
- Explore AI Automation Services.
- Start with Funding Readiness.

Avoid vague CTAs:

- Learn More.
- Click Here.
- Submit.

## Copy checklist

- [ ] Short sentences.
- [ ] Plain business language.
- [ ] Benefits before features.
- [ ] No hype that sounds like guaranteed money.
- [ ] Repeats the CTA naturally.
- [ ] Explains why Canva + ChatGPT + GitHub + website work together.

## Visual checklist

- [ ] High contrast.
- [ ] Large text.
- [ ] Strong spacing.
- [ ] One main visual per section.
- [ ] Consistent brand colors.
- [ ] No cluttered screenshots.
- [ ] Canva designs match the page purpose.

## Lead capture checklist

- [ ] Form works.
- [ ] Email/contact routing works.
- [ ] Thank-you message works.
- [ ] Follow-up copy is ready.
- [ ] Lead source is tracked.
- [ ] Privacy/contact language is available.

## Affiliate and compliance checklist

- [ ] Affiliate links are disclosed.
- [ ] Funding claims are careful.
- [ ] Income claims are not guaranteed.
- [ ] Tax/legal topics are framed as educational or referred to professionals.
- [ ] Investment language avoids promises.
- [ ] Tool recommendations are presented as options, not guarantees.

Suggested disclosure:

```text
Some links may be affiliate or partner links. Information is provided for educational and business-planning purposes only. Funding, approval, income, tax, legal, or investment outcomes are not guaranteed.
```

## Weekly website improvement ideas

- [ ] Improve hero headline.
- [ ] Add a better Canva banner.
- [ ] Add a checklist download form.
- [ ] Add a new offer card.
- [ ] Add a better CTA.
- [ ] Add proof-of-work screenshot.
- [ ] Add FAQ section.
- [ ] Add affiliate disclosure.
- [ ] Improve mobile layout.
- [ ] Add tracking notes.

## Performance questions

Ask weekly:

1. Did people understand the offer?
2. Did people click the CTA?
3. Did people submit the form?
4. Did people ask questions?
5. Did any traffic source produce better leads?
6. Which Canva asset helped most?
7. What can be simplified?
8. What can be repeated?
