## Placement recommendation

Place this section after:

- Homepage hero.
- Free checklist lead magnet.
- Main offer cards.

Place before:

- Full affiliate/tool marketplace.
- Long creative mythos sections.
- Footer.

## Mobile best practices

- Stack cards vertically.
- Keep each card headline short.
- Use readable button text.
- Do not use tiny repo names in images.
- Make each card image tappable if possible.
- Keep bullets to 3-4 per card.
