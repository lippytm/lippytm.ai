# Canva + ChatGPT + GitHub Workflow Guide

Purpose: provide a repeatable workflow for creating, publishing, tracking, and improving creative business campaigns.

## Workflow summary

```text
1. Strategy brief in GitHub
2. ChatGPT creates copy and variations
3. Approved copy saved in GitHub
4. Canva creates visual assets
5. Assets are published to website/social/bots
6. Results are logged
7. ChatGPT suggests improvements
8. GitHub stores the improved version
```

## Step 1: Create the campaign brief

Create a campaign folder or GitHub issue with:

- Campaign name.
- Audience.
- Main problem.
- Main promise.
- Offer.
- CTA.
- Channels.
- Assets needed.
- Compliance notes.
- Success metric.

Example:

```md
Campaign: AI Business Funding Launch Kit
Audience: startup and small business owners
Problem: they need funding, organization, marketing, and automation
Promise: get funding-ready and AI-ready with one practical checklist
CTA: download the free checklist
Success metric: checklist downloads and consultation requests
```

## Step 2: Ask ChatGPT for campaign copy

Prompt template:

```text
Create campaign copy for [campaign name].
Audience: [audience].
Problem: [problem].
Offer: [offer].
CTA: [CTA].
Tone: practical, energetic, trustworthy, business-focused.
Include: 5 social posts, 3 reel scripts, 1 landing page hero, 1 email follow-up, 1 Canva prompt, and compliance notes.
Avoid guaranteed funding, income, tax, legal, or investment claims.
```

## Step 3: Save approved copy in GitHub

Save final copy into the correct files:

- `landing-page-copy.md`
- `social-posts.md`
- `reel-scripts.md`
- `email-follow-up.md`
- `canva-prompts.md`
- `bot-flow.md`

## Step 4: Build in Canva

Use the Canva prompt library and campaign copy.

Recommended Canva project folders:

```text
lippytmAI GetBizFunds/
  Brand Kit/
  AI Business Funding Launch Kit/
  BotBuilders ManyChat Lead Machine/
  Twin.so Affiliate Funnel/
  Website Banners/
  Social Posts/
  Pitch Decks/
  Lead Magnets/
  QR Flyers/
  Merchandise/
```

## Step 5: Export assets

Suggested formats:

- Website banner: PNG or WebP.
- Social post: PNG/JPG.
- Reel cover: PNG/JPG.
- Lead magnet/checklist: PDF.
- Flyer: PDF Print.
- Pitch deck: PDF + editable Canva link.

## Step 6: Publish

Publish assets to:

- lippytmai.getbizfunds.com.
- Facebook.
- Instagram.
- ManyChat/BotBuilders flows.
- Email/follow-up messages.
- QR code print materials.
- GitHub progress updates.

## Step 7: Track results

Track in a performance log:

- Date published.
- Channel.
- Asset name.
- Views.
- Clicks.
- Replies.
- Leads.
- Affiliate clicks.
- Conversions.
- Notes.

## Step 8: Improve with ChatGPT

Prompt template:

```text
Review these campaign results and suggest improvements.
Campaign: [name]
Assets published: [list]
Results: [metrics]
Goal: [goal]
Suggest: headline improvements, CTA improvements, design direction, follow-up message, next test, and what to stop doing.
```

## Step 9: Update GitHub

Update:

- Campaign file.
- Performance log.
- Canva inventory.
- Website copy.
- Next GitHub issue/task.

## Minimum viable weekly workflow

Every week:

1. Pick one offer.
2. Ask ChatGPT for a content batch.
3. Save approved copy to GitHub.
4. Create 5 Canva assets.
5. Publish 3 pieces of content.
6. Improve one website section.
7. Track results.

## Best practices

- Keep all approved copy in GitHub.
- Keep Canva as the visual production layer.
- Keep ChatGPT as the strategic and copy improvement layer.
- Keep the website as the conversion layer.
- Keep issues as the task management layer.
- Do not overload one post with every project.
- Each campaign should have one audience, one problem, one CTA.
