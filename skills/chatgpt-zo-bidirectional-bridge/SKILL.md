# ChatGPT ↔ Zo Bidirectional Bridge

## Purpose

Make ChatGPT Business and lippytmai.zo.computer operate as a two-way business-building system.

## Operating model

1. **Zo → ChatGPT**: export current workspace, GitHub map, public URL map, Skills, workflows, campaigns, eBooks, templates, and build state into a ChatGPT-ready package.
2. **ChatGPT → Zo**: import ChatGPT outputs as raw source, process into classified markdown, promote strong assets into durable workspace/GitHub paths, and publish when appropriate.
3. **Round trip**: every major ChatGPT session should return improved files, prompts, plans, code specs, campaign assets, Canva briefs, Zapier maps, or AgentBot swarm designs.

## Guardrails

- Do not include secrets in exports.
- Keep raw ChatGPT exports separate from processed materials.
- Require human approval before public financial claims, payment changes, wallet changes, external messages, or destructive edits.
- Treat funding, crypto, tax, legal, and investment content as educational unless professionally verified.

- workspace areas touched

- GitHub mirror targets
