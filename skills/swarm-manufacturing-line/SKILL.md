# Swarm Manufacturing Line

## Purpose

Mass-produce useful, safer, versioned, interoperable, and productizable AgentBots and swarms without turning them into uncontrolled generic agents.

## Manufacturing process

1. Select a business lane: funding leads, affiliate content, eBook funnel, AI coding, education, entertainment, Zapier automation, or tool/adaptor bridge.
2. Choose a standard swarm template instead of starting from scratch.
3. Define the swarm mission, buyer/user, revenue path, input sources, outputs, and approval gates.
4. Select required skills from `AGENTS.md`.
5. Create the agent spec, task packet, result packet, and quality-control checklist.
6. Store specs in GitHub before repeated use.
7. Run a safe pilot on one narrow task.
8. Review outputs for accuracy, safety, value, and business fit.
9. Package the working swarm as a reusable template, prompt pack, Zapier workflow, GitHub issue template, or product offer.
10. Add metrics, improvement loops, rollback plan, and self-healing notes.

## Standard factory roles

- Architect: defines system pattern.
- Skill Orchestrator: selects skill stack.
- Adapter Builder: connects toolkit/platform.
- Builder Agent: creates assets, code, docs, or automation.
- QA/Safety Agent: validates risk and quality.
- Publisher Agent: publishes only when checks are satisfied.
- Revenue Agent: connects output to funnel, offer, affiliate path, lead capture, or product.
- Memory Agent: updates AGENTS.md, workflow docs, GitHub notes, and logs.

## Output required

For each manufactured swarm, return:

- Swarm name
- Business lane
- Mission
- Target user/buyer
- Skill stack
- Input sources
- Output products
- Toolkit integrations
- Approval gates
- Quality-control checklist
- GitHub path
- Zapier path
- ChatGPT Business prompt path
- Revenue path
- Pilot task
- First measurable success metric
