# LippytmAI Skill Orchestrator

## Purpose

Choose the right skill stack before building an agent, workflow, campaign, automation, eBook, page, or swarm.

## Core workflow

1. Identify the business outcome: revenue, lead capture, content, education, automation, product, safety, or publishing.
2. Select the smallest useful skill stack.
3. Define agent roles and handoffs.
4. Decide which assets should be created: page, article, GitHub doc, Zapier template, Canva prompt, eBook section, or issue.
5. Add safety and review steps when money, finance, legal, health, identity, or external automation is involved.
6. Write or update durable workflow documentation.
7. Create a new skill only when a workflow repeats, becomes business-critical, or needs safer execution.
