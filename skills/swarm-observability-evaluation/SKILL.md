# Swarm Observability and Evaluation

## Purpose

Make LippytmAI swarms measurable, improvable, and auditable.

## Core workflow

1. Define the mission and expected output.
2. Choose 3-7 metrics that matter.
3. Define logging location: GitHub issue, workflow note, spreadsheet, campaign log, or Zo page changelog.
4. Add quality checks before publishing or automating.
5. Add a review cadence: per output, daily, weekly, or campaign-based.
6. Convert failures into skill updates, workflow improvements, or safer defaults.

## Recommended metrics

Use only the metrics that fit the task:

- Revenue path clarity
- Lead capture quality
- Conversion CTA strength
- Content usefulness
- Technical correctness
- Safety/compliance risk
- Automation reliability
- Time saved
- Reusability
- GitHub documentation quality
- Public page quality
- Follow-up completeness

## Evaluation scorecard

Rate 1-5:

- Outcome achieved
- User value
- Revenue potential
- Safety
- Maintainability
- Reusability
- Next-step clarity

## Output format

Return:

- Mission
- Metrics
- Logging location
- Review cadence
- Scorecard
- Failure modes
- Improvement actions
- Skill updates needed
