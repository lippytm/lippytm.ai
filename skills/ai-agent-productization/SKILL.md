# AI Agent Productization

## Purpose

Turn agentic workflows and skill-based systems into practical products that can create revenue, leads, authority, or business growth.

## Productization workflow

1. Identify the repeatable problem the agent solves.
2. Choose the product type:
   - lead magnet
   - eBook
   - checklist
   - paid implementation service
   - done-for-you automation
   - affiliate resource hub
   - free tool
   - course or workshop
   - SaaS prototype
3. Define the buyer, pain, promise, proof, CTA, and delivery method.
4. Package the system into a simple first offer.
5. Create sales copy, onboarding steps, support boundaries, and disclaimers.
6. Add GitHub documentation and public page or campaign asset.
7. Add automation for intake, follow-up, measurement, and improvement.

## Best practices

- Start with a narrow offer before expanding into a platform.
- Sell outcomes, not just technology.
- Use education to build trust before asking for a larger commitment.
- Keep pricing and deliverables clear.
- Avoid income or funding guarantees.
- Build reusable templates and prompts from every delivery.
- Preserve improvements in GitHub and workspace workflow files.

## Output format

For a product idea, return:

- Product name
- Audience
- Problem
- Promise
- Deliverables
- Funnel
- Price/monetization options
- Automation path
- Risk/disclaimer notes
- First build step
