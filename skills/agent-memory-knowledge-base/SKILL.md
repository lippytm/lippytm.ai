# Agent Memory and Knowledge Base

## Purpose

Keep LippytmAI agent knowledge durable, searchable, useful, and safe without turning memory files into clutter.

## Memory workflow

1. Decide whether the knowledge is durable or temporary.
2. Put durable routing knowledge in `AGENTS.md` or a project-level `AGENTS.md`.
3. Put detailed plans in `Records/Plans/` or `Records/Workflows/`.
4. Put campaign assets in `Campaigns/`.
5. Put product drafts in `Ebooks/`.
6. Put public-source copies in GitHub.
7. Avoid storing secrets, raw private data, or unnecessary personal data.

## What to save

- Stable project purpose
- Important repository roles
- Workflow instructions
- Reusable prompts
- Offer architecture
- Automation templates
- Skill activation maps
- Public URL maps
- GitHub commit notes

## What not to save

- Secrets or API keys
- Raw credentials
- Unnecessary private lead data
- Long chat transcripts unless condensed
- Stale brainstorming that is not useful
- Duplicated content without a reason

## Output format

Return:

- Memory type
- Best storage location
- Summary to save
- Files to update
- GitHub mirror path
- Retention or cleanup note
