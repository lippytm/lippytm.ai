# lippytm.ai Quality Checklist

## Purpose

Keep the lippytm.ai control hub clear, useful, professional, safe, and ready to connect to website, Canva, CRM, social media, and repository expansion work.

## Clarity checklist

- [ ] The repo explains what lippytm.ai is in plain English.
- [ ] The primary CTA is clear: Explore the Roadmap.
- [ ] The roadmap explains the system without overwhelming the visitor.
- [ ] The website copy can be understood by a first-time visitor.
- [ ] The Canva card can be understood in 3 seconds.

## Link checklist

- [ ] Canva card links to `/roadmap#explore`.
- [ ] Website roadmap section links to checklist, bot workflow, AllBots map, and systems review.
- [ ] Social posts link to the correct destination.
- [ ] GitHub issue links are correct.

## CTA checklist

- [ ] One main CTA per card/post.
- [ ] CTA explains the next action.
- [ ] CTA connects to a CRM tag.
- [ ] CTA has a follow-up message.

## Compliance checklist

- [ ] No guaranteed funding claims.
- [ ] No guaranteed income claims.
- [ ] No guaranteed approval claims.
- [ ] No tax/legal/investment advice presented as professional advice.
- [ ] Affiliate links are disclosed where used.
- [ ] Testimonials are real if used.

## Canva quality checklist

- [ ] Headline readable on phone.
- [ ] CTA button visible.
- [ ] No overcrowded nodes.
- [ ] Professional enough for LinkedIn.
- [ ] Energetic enough for Instagram/Facebook.
- [ ] Exported in square, vertical, LinkedIn, and website sizes.

## GitHub quality checklist

- [ ] Source copy is saved before publishing.
- [ ] Performance log is updated weekly.
- [ ] New ideas become issues or files.
- [ ] All important changes have clear commit messages.

## Best practice

Quality is Job #1. Make the system clear before making it bigger.
