# Affiliate Revenue Cycle

This workflow explains how the portfolio can grow revenue through affiliate and partner paths in a repeatable way.

## Cycle

1. identify offers suitable for affiliate promotion
2. route partner and affiliate interest clearly
3. track partner-origin lead quality
4. improve premium and service routing for partner-origin leads
5. measure activation and repeat value
6. record lessons into workflows, templates, and routing rules

## Best Practices
- choose affiliate paths that match real offer value
- keep partner-origin routing measurable
- improve clarity before scaling volume
- use repeat value and activation quality as key affiliate metrics
