# Lane Template Bootstrap

This workflow explains how to use the BrainKit lane templates to start new repositories in a structured way.

## Goal

Create new repos faster without losing lane clarity, quality structure, or integration boundaries.

## Steps

1. choose the primary lane
2. run the lane bootstrap script
3. apply lane metadata
4. review README, ROADMAP, and ARCHITECTURE stubs
5. fill in integration and quality details
6. score the repo and identify gaps

## Best Practices

- choose lane before naming deeper implementation details
- keep the first version small and structured
- use scorecards early to catch missing basics
- do not mix lab and production intent in the same starting template
