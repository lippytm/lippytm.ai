# Awareness to Mission

This workflow explains how repo awareness and scorecard signals should become structured improvement missions.

## Goal

Turn awareness data into clear next actions instead of leaving it as passive metadata.

## Steps

1. read repo awareness
2. read scorecard output
3. identify the main gap category
4. choose the right mission type
5. route to the owning lane
6. apply governance before execution

## Common Mission Types
- awareness completion mission
- documentation readiness mission
- integration readiness mission
- quality readiness mission
- promotion readiness mission
- monetization readiness mission

## Best Practices
- use bounded missions
- let lane ownership drive routing
- prioritize high-risk and public-surface repos first
- convert repeated gaps into template improvements
