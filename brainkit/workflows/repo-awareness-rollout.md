# Repo Awareness Rollout

This workflow explains how to roll repo-awareness across active repositories.

## Goal

Give each active repo a simple, explicit statement of:

- primary lane
- promotion stage
- value role
- risk level
- management status

## Suggested Rollout Order

1. hub repo
2. control repo
3. swarm repo
4. revenue repo
5. commerce repo
6. product repos
7. knowledge repos
8. lab repos

## Steps

1. classify the repo by lane
2. apply metadata file or awareness block
3. compare repo structure to lane template
4. run scorecard
5. open improvement tasks for missing items

## Best Practices

- roll out awareness to core repos first
- use lane rules consistently
- do not overcomplicate awareness files
- let awareness improve loops, routing, and promotion decisions
