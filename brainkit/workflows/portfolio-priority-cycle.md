# Portfolio Priority Cycle

This workflow explains how to prioritize improvements across the full portfolio using awareness, scorecards, risk, public surface status, and money-first order.

## Cycle

1. read repo awareness
2. run scorecards
3. rank repos by priority
4. check money-first order for revenue-critical work
5. generate bounded missions
6. govern and execute
7. rescore and record lessons

## Best Practices

- use one repeatable cycle across the portfolio
- prioritize critical and public-facing repos first
- keep creative and lab work moving without displacing urgent business work
- feed recurring gaps back into templates, policies, and workflows
