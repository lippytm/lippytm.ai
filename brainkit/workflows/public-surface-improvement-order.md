# Public Surface Improvement Order

This workflow explains how to order improvements for public-facing repos.

## Priority Order

1. main offer pages
2. intake forms
3. checkout handoff points
4. assistant and bot handoffs
5. secondary pages

## Best Practices

- improve main entry pages first
- protect high-impact forms and routing paths
- keep payment logic outside public pages where possible
- prefer clarity and next-step usefulness over feature sprawl
