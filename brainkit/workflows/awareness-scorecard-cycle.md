# Awareness Scorecard Cycle

This workflow explains how awareness files and scorecards should work together as a repeating improvement cycle.

## Cycle

1. read repo awareness
2. run scorecard
3. classify gaps
4. generate mission
5. govern mission
6. execute bounded improvements
7. rescore repo
8. record lessons

## Best Practices

- use the same cycle across lanes
- keep missions small enough to verify
- prioritize higher-risk repos first
- feed repeated gaps back into templates and policies
