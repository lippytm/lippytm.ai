# Hub Lane Template

Use this template for repositories that define standards, contracts, policies, templates, and manufacturing guidance.

## Recommended files
- README.md
- ROADMAP.md
- ARCHITECTURE.md
- docs/standards/
- docs/contracts/
- docs/quality/
- docs/policies/

## Metadata block
```yaml
primary_lane: hub
promotion_stage: 5
value_role: platform
risk_level: critical
public_surface: false
brainkit_managed: true
fleet_managed: true
```

## Best practices
- keep standards reusable
- keep policy clear and specific
- treat this lane as manufacturing tooling for the rest of the fleet
