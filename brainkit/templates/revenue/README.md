# Revenue Lane Template

Use this template for offers, landing pages, forms, funnels, and conversion-focused repositories.

## Recommended files
- README.md
- ROADMAP.md
- ARCHITECTURE.md
- MONETIZATION.md
- docs/offers/
- docs/funnels/
- docs/integrations/
- site/ or app/
- tests/

## Metadata block
```yaml
primary_lane: revenue
promotion_stage: 4
value_role: direct
risk_level: high
public_surface: true
brainkit_managed: true
fleet_managed: true
```

## Best practices
- keep messaging practical and clear
- separate lead capture from payment logic
- design multiple journeys without making the site confusing
