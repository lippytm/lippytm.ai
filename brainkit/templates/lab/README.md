# Lab Lane Template

Use this template for experiments, prototypes, diagnostics, and high-variance research repositories.

## Recommended files
- README.md
- ROADMAP.md
- EXPERIMENTS.md
- docs/hypotheses/
- docs/results/
- sandboxes/
- tests/ when applicable

## Metadata block
```yaml
primary_lane: lab
promotion_stage: 1
value_role: experimental
risk_level: low
public_surface: false
brainkit_managed: true
fleet_managed: true
```

## Best practices
- keep experiments clearly labeled
- define success criteria before broad expansion
- use this lane to test ideas before promoting them into production-oriented lanes
