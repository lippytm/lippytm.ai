# Knowledge Lane Template

Use this template for educational, media, narrative, worldbuilding, and knowledge-product repositories.

## Recommended files
- README.md
- ROADMAP.md
- docs/education/
- docs/commercialization/
- docs/canon/ or docs/media/
- products/
- prompts/

## Metadata block
```yaml
primary_lane: knowledge
promotion_stage: 2
value_role: direct
risk_level: moderate
public_surface: true
brainkit_managed: true
fleet_managed: true
```

## Best practices
- keep educational and creative value strong on its own
- separate mythos-heavy exploration from buyer-facing sales surfaces
- use product ladders instead of forcing every idea into the same offer format
