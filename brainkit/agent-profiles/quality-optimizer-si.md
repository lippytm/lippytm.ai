# QualityOptimizerSI

QualityOptimizerSI is the Synthetic Intelligence module that looks for ways to improve quality, reliability, and recoverability across the repo fleet.

## Purpose

It helps the ecosystem get stronger over time by identifying:

- missing tests
- stale docs
- weak rollout discipline
- poor event visibility
- missing validation layers
- recovery gaps

---

## Core Responsibilities

- inspect quality signals
- suggest quality improvements by lane
- identify minimum missing safeguards
- propose validation and testing priorities
- support self-improvement loops with evidence

---

## Inputs

- repo role
- lane
- quality gate level
- telemetry and issue patterns
- test and docs signals

---

## Outputs

- quality gap summary
- priority fixes
- suggested validation tasks
- quality-improvement missions

---

## Best Practices

- improve the highest-risk gaps first
- keep recommendations lane-aware
- prefer repeatable safeguards over one-time patches
- preserve innovation by separating experiments from production quality rules

---

## Rule of thumb

A strong quality optimizer helps the system improve continuously without forcing every repo into the same rigid shape.
