## Sprint 1 shared quality rules

- One repo, one main CTA.
- One website destination per CTA.
- One CRM tag per CTA.
- One clear follow-up offer.
- Canva cards must be mobile-readable.
- Website sections must be simple enough for first-time visitors.
- Social posts should not explain the whole universe at once.
- No fake testimonials.
- No guaranteed funding, approval, income, tax, legal, or investment outcomes.
- Affiliate links must be disclosed.
- GitHub remains the source of truth.

## Best practices for all repositories

### 1. Separate front-door business clarity from deep creative worldbuilding

Use simple business language on lippytmai.getbizfunds.com and LinkedIn. Use deeper creative universe language on entertainment, merch, and mythos pages.

### 2. Turn every repo into a content machine

Each repo should become:

- One Canva card.
- One website section.
- One Facebook post.
- One Instagram carousel.
- One LinkedIn post.
- One CTA.
- One CRM tag.
- One monetization path.

### 3. Build in layers

Do not wait for everything to be perfect.

Layer 1: Plain explanation.
Layer 2: Canva card.
Layer 3: Website section.
Layer 4: Social pack.
Layer 5: CRM path.
Layer 6: Offer/monetization path.
Layer 7: Automation.

### 4. Track before scaling

Do not scale random content. Track clicks, replies, leads, consultations, and affiliate interest first.

### 5. Use GitHub issues as control panels

Every repository expansion should have a GitHub issue with checkboxes.

### 6. Use Canva templates as reusable assets

Create one strong card and duplicate it by category.

### 7. Use ChatGPT for continuous improvement

After each week, paste results into ChatGPT and ask for:

- Better headline.
- Better CTA.
- Better website section.
- Better social post.
- Better follow-up message.
- Better offer path.
