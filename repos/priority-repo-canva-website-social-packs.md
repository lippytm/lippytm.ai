## Universal design direction

### Canva portfolio card format

Use one consistent portfolio card style across all repos.

Recommended dimensions:

- Square: 1080 x 1080 for Facebook/Instagram.
- Vertical: 1080 x 1920 for reels/stories.
- Website card: 1600 x 900 or responsive web banner.
- LinkedIn graphic: 1200 x 627.

### Shared visual system

Use the same layout pattern:

```text
Top: Repo category badge
Middle: Big outcome headline
Bottom: Repo name + CTA
Side/Background: AI network, dashboard, bot, website, or creative system visual
```

### Shared CTA options

- Explore the Roadmap
- Build the Workflow
- View the Portfolio
- Start the Business Money Engine
- Request a Business Systems Review
- Get Funding-Ready and AI-Ready

### Shared compliance footer where needed

```text
Educational and business-planning information only. Results, funding, income, approval, tax, legal, or investment outcomes are not guaranteed.
```

# Cross-repository best practices

## 1. Every repo needs one plain-English explanation

Use this formula:

```text
[Repo name] helps [audience] solve [problem] by [practical method].
```

## 2. Every repo needs one Canva card

The card should answer:

- What is it?
- Who is it for?
- What does it help with?
- What should the viewer do next?

## 3. Every repo needs one website section

Do not make every repo a full website at first. Start with a short portfolio section and CTA.

## 4. Every repo needs one social pack

Minimum:

- 1 Facebook post.
- 1 Instagram carousel.
- 1 LinkedIn post.

## 5. Every repo needs one GitHub issue

Turn the content pack into tasks.

## 6. Keep front-door business content clear

Use the website and LinkedIn for practical business language. Use Instagram and creative project pages for deeper mythos and futuristic brand worldbuilding.

## 7. Track what creates movement toward money

Track:

- Clicks.
- Replies.
- Leads.
- Consult requests.
- Affiliate clicks.
- Product sales.
- Service interest.

## 8. Reuse every asset

One repo content pack can become:

- Website section.
- Canva portfolio card.
- Facebook post.
- Instagram carousel.
- LinkedIn post.
- Pitch deck slide.
- QR flyer.
- Email.
- Bot FAQ.
- GitHub issue.

## 9. Quality rules

- Clear before clever.
- Useful before flashy.
- One CTA per asset.
- Mobile-readable designs.
- No fake testimonials.
- No guaranteed outcomes.
- Affiliate links disclosed.
- Business/funding/tax/legal/investment claims handled carefully.
