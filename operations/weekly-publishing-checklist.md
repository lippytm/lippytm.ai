# Weekly Publishing Checklist

Purpose: keep the Business of Businesses Brand Money Engine moving every week with Canva assets, website improvements, GitHub updates, AI bot flows, affiliate promotion, and lead tracking.

## Weekly goal

Publish enough useful content to create visibility, capture leads, test offers, and improve the money engine without getting stuck in planning.

## Weekly rhythm

### Monday: choose the offer

Pick one offer to promote:

- AI Business Funding Launch Kit.
- Startup Readiness Kit.
- Business Growth Automation Kit.
- AI Bot Builder Package.
- Canva Brand Money Engine Pack.
- Twin.so affiliate funnel.
- BotBuilders + ManyChat Lead Machine.

Actions:

- [ ] Choose one primary offer.
- [ ] Choose one target audience.
- [ ] Choose one CTA.
- [ ] Update GitHub campaign notes.

### Tuesday: create Canva assets

Create or update:

- [ ] 1 website/banner graphic.
- [ ] 2 social square posts.
- [ ] 1 reel cover.
- [ ] 1 PDF/checklist/lead magnet asset.
- [ ] 1 QR flyer or service menu asset.

Best practice: one campaign idea should become at least five assets.

### Wednesday: website improvement

Improve one website item:

- [ ] Homepage section.
- [ ] Landing page section.
- [ ] CTA button.
- [ ] Contact/lead form.
- [ ] Affiliate disclosure.
- [ ] Proof-of-work screenshot.
- [ ] Mobile layout.

Best practice: small weekly improvements beat waiting for a perfect redesign.

### Thursday: publish and distribute

Publish:

- [ ] 1 Facebook post.
- [ ] 1 Instagram post or reel.
- [ ] 1 website update.
- [ ] 1 chatbot or follow-up message improvement.
- [ ] 1 GitHub progress update.

Optional:

- [ ] Share to relevant groups where allowed.
- [ ] Send to a warm contact.
- [ ] Add to email or DM follow-up.

### Friday: track and improve

Record:

- [ ] Posts published.
- [ ] Website visits.
- [ ] Form submissions.
- [ ] Affiliate clicks.
- [ ] Bot conversations.
- [ ] Replies/messages.
- [ ] Consult requests.
- [ ] Sales/conversions.
- [ ] Best-performing content.

Then decide:

- [ ] What to repeat.
- [ ] What to improve.
- [ ] What to stop.
- [ ] What to build next.

## Daily micro-actions

Do at least one:

- [ ] Publish one helpful post.
- [ ] Improve one Canva asset.
- [ ] Improve one website sentence.
- [ ] Add one GitHub note/checklist item.
- [ ] Message one potential lead or partner.
- [ ] Improve one chatbot question/answer.
- [ ] Save one useful tool or affiliate opportunity.

## Content ratio

Use this mix:

- 40% educational business/funding/automation tips.
- 25% proof of work and project updates.
- 20% offer/CTA posts.
- 10% affiliate/tool recommendations.
- 5% creative mythos/brand universe content.

## Quality rules

- Every post should have one clear point.
- Every campaign should have one clear CTA.
- Every website page should have a next step.
- Every affiliate link should have disclosure.
- Every funding/income-related message should avoid guarantees.
- Every design should be readable on mobile.
- Every campaign should be tracked in GitHub.

## Monthly review

At the end of each month:

- [ ] Identify top 3 posts.
- [ ] Identify top 3 traffic sources.
- [ ] Identify best offer response.
- [ ] Improve the main landing page.
- [ ] Create one new lead magnet or paid mini-product.
- [ ] Archive weak ideas or rewrite them.
- [ ] Update the offer stack.
- [ ] Update the affiliate/tool registry.

## Money focus

Prioritize actions closest to revenue:

1. Lead capture form works.
2. Free checklist is available.
3. Follow-up message is ready.
4. Primary offer is clear.
5. CTA is visible.
6. Social posts point to the website.
7. Website points to the next step.
8. Replies are handled quickly.
