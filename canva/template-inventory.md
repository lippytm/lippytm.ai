# Canva Template Inventory

Purpose: organize all Canva assets for the lippytmAI GetBizFunds Business of Businesses Brand Money Engine.

Use this inventory to track what needs to be created, what is finished, where it is used, and what campaign it belongs to.

## Naming convention

Use this format:

```text
campaign-name_asset-type_version_date
```

Example:

```text
ai-business-funding-launch-kit_ebook-cover_v1_2026-05
```

## Asset status options

- Idea.
- Draft.
- Ready for review.
- Published.
- Needs update.
- Archived.

## Export checklist

Before publishing any Canva asset:

- [ ] Mobile-readable.
- [ ] Correct brand name.
- [ ] One clear CTA.
- [ ] No exaggerated funding/income claim.
- [ ] Affiliate disclosure where needed.
- [ ] File name follows naming convention.
- [ ] Source copy is saved in GitHub.
- [ ] Export format is correct:
  - PNG/WebP for website.
  - PNG/JPG for social.
  - MP4 for videos.
  - PDF Print for flyers/lead magnets.

## Storage checklist

- [ ] Canva original saved in correct folder/project.
- [ ] Exported file saved locally/cloud.
- [ ] Website version uploaded.
- [ ] Social version published or scheduled.
- [ ] GitHub notes updated.
- [ ] Performance tracked weekly.
