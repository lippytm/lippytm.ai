# Repository Card Design System for All lippytm Repositories

Purpose: create a flexible Canva design system that can turn every lippytm repository into a professional portfolio card, website section, social graphic, pitch deck slide, and campaign asset.

## System goal

Every repository should be able to produce:

- 1 Canva portfolio card.
- 1 website card/section.
- 1 Facebook post graphic.
- 1 Instagram carousel.
- 1 LinkedIn graphic.
- 1 pitch deck slide.
- 1 QR flyer or business card if useful.

## Master design rule

All cards should look connected, but not identical.

Use a consistent structure:

```text
Category Badge
Main Repo/Offer Headline
Outcome Subheadline
Central Visual System
CTA Button
Footer Brand
```

Then vary the visual style by category.

## Repository card production workflow

1. Pick repo.
2. Assign category.
3. Choose template family.
4. Write plain-English outcome.
5. Create Canva prompt.
6. Generate/design card in Canva.
7. Export 4 sizes.
8. Add card to website portfolio section.
9. Publish social pack.
10. Track results.
11. Improve card copy/design based on response.

## Master Canva prompt template

```text
Create a Canva portfolio card for [repository/project name].

Category: [category]
Audience: [audience]
Main headline: [headline]
Subheadline: [subheadline]
Microcopy: [microcopy]
CTA button: [CTA]
Footer: lippytm.ai • Business of Businesses

Visual metaphor: [visual metaphor]
Core nodes/icons to include: [nodes/icons]
Style: [professional/futuristic/educational/creative/etc.]
Format: mobile-readable, clean, high-impact, suitable for website, Facebook, Instagram, LinkedIn, and pitch decks.
Avoid clutter and avoid guaranteed income/funding claims.
```

## Best practices

- Create the lippytm.ai Control Hub card first.
- Use that as the master style reference.
- Create category-specific variants, not random styles.
- Keep all approved prompts in GitHub.
- Keep all exported file names consistent.
- Track which card gets the most clicks or replies.
- Reuse winning layouts across repositories.
- Keep public business cards practical; save wild mythos visuals for creative/IP categories.
