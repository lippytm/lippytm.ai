## Suggested color direction

Use the existing brand direction where available. If not set yet, use a professional technology palette:

- Deep navy or charcoal background.
- Electric blue or cyan accents.
- White readable headline text.
- Green or gold accent only for growth/money signals.
- Avoid too many colors in one card.

## Typography guidance

- Use a bold modern sans-serif for the headline.
- Use a clean readable sans-serif for body text.
- Keep the CTA button large enough to read on a phone.
- Avoid script fonts.
- Avoid tiny technical text.
