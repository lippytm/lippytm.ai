# Canva Design Prompt Library

Use this file as the creative prompt bank for Canva assets connected to lippytmai.getbizfunds.com, lippytm.ai, GitHub, BotBuilders, ManyChat, Twin.so, and the larger Business of Businesses brand.

## Brand design direction

Style keywords:

- Futuristic business finance.
- AI automation control tower.
- Trustworthy startup funding.
- Creative digital agency.
- Clean, bold, readable, mobile-first.
- High-tech but practical.

Avoid:

- Overcrowded designs.
- Guaranteed income claims.
- Confusing sci-fi language on front-door sales pages.
- Tiny text that cannot be read on phones.

## Best practices for Canva production

- Export website assets as PNG or WebP.
- Export print/flyer assets as PDF Print.
- Keep editable Canva originals organized by campaign name.
- Use consistent file names:
  - `campaign-name_asset-type_version_date`
  - Example: `ai-business-funding-launch-kit_ebook-cover_v1_2026-05`
- Save copy in GitHub before finalizing designs.
- Keep disclaimers readable.
- Test thumbnails on mobile before publishing.
