# 42 Websites Sales Capture Pages and Ad Copy Review Framework

## Mission

Review every aspect of each website sales capture page, ad copy system, CTA structure, offers, hooks, and conversion flow across the 42 Web3 ecosystem websites.

This framework exists so the review process is:
- systematic
- repeatable
- modular
- testable
- easier to improve over time

---

## Core Rule

Every website must be reviewed in 6 layers:

1. **Audience Fit**
2. **Sales Capture Page Structure**
3. **Offer Clarity**
4. **CTA / Conversion Logic**
5. **Ad Copy System**
6. **Testing / Debugging / Improvement**

---

## Part 2 — Sales Capture Page Review

Every sales capture page should be reviewed section by section.

### 1. Hero Section
Check:
- Is the headline clear?
- Is the subheadline clear?
- Is the audience obvious?
- Does the page immediately explain what the site does?
- Is the first CTA visible?
- Is the message too broad or too vague?

### 2. Offer Section
Check:
- What is being sold?
- Is the offer obvious?
- Is the price visible if needed?
- Is the transformation clear?
- Is it too complicated?
- Are there too many competing offers?

### 3. Problem / Solution Section
Check:
- Does it explain the pain point?
- Does it explain the better future?
- Does it connect to what the audience wants?
- Does it show why this website matters?

### 4. Trust / Proof Section
Check:
- Are there examples, use cases, or proof points?
- Are there product screenshots, feature blocks, or roadmap proof?
- Is there enough credibility for the visitor to keep reading?

### 5. Build / Buy / Customize Section
Check:
- Can the user build it?
- Can the user buy it?
- Can the user customize it?
- Is the next step clear?

### 6. CTA Section
Check:
- Is the CTA specific?
- Is the CTA repeated enough?
- Is the CTA tied to the promise?
- Is it low friction?
- Is it consistent across page sections?

### 7. Footer / Exit Flow
Check:
- Are there ecosystem links?
- Is there a fallback CTA?
- Is there a contact or next-step path?
- Is there a way to enter another related site?

---

## Part 3 — Sales Capture Page Scoring

Each page should be scored 1-5 in these areas:
- headline clarity
- audience fit
- offer clarity
- CTA strength
- trust/credibility
- ecosystem connection
- visual/message consistency
- readiness for testing

Total score determines:
- 32-40 = ready to test
- 24-31 = needs improvement
- below 24 = needs rewrite

## Part 11 — Testing Checklist

Before any page goes live for paid traffic, check:
- links work
- CTAs work
- capture forms work
- copy matches the offer
- page matches the ad
- mobile layout works
- related site links work
- visual identity matches the category
- page has one clear main action
- page is ready for debugging and iteration

---

## Part 12 — Debugging and Improvement Loop

Use this loop for every website:

1. Review page
2. Rewrite weak sections
3. Add new ad copy variants
4. Test CTA variants
5. Test different hooks
6. Compare page performance
7. Keep winning versions
8. turn winners into templates for the other sites

## Part 14 — Best Practices

- One website = one primary audience at a time
- One page = one primary action at a time
- Keep offers simple
- Match the ad to the page exactly
- Use AI to generate many hook variants
- Keep the first CTA visible early
- Cross-link intelligently, not chaotically
- Do not overload the visitor with every offer at once
- Build reusable ad-copy templates for all 42 sites
- Turn the best pages into repeatable systems

---

## Closing Doctrine

Every website needs its own sales capture page review, ad copy review, CTA review, and offer review.

The goal is not just to write more copy.
The goal is to make every website clear enough to sell, strong enough to test, and structured enough to improve repeatedly.

First review everything.
Then improve everything.
Then test everything.
Then turn the winning patterns into templates across the 42-website ecosystem.
