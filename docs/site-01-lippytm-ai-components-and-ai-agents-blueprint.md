# Site 01 — lippytm.ai Components and AI Agents Blueprint

## Mission

`lippytm.ai` is the central hub of the 42 Web3 ecosystem websites.

It is not just a homepage. It is the:
- ecosystem portal
- identity hub
- navigation root
- product directory
- AI agent command center
- business-of-businesses entry point
- control gateway into the other 41 websites

This document defines the full component list needed for `lippytm.ai` and the AI agents required to make it work.

---

## Primary Purpose

The first website should help users do 5 things:

1. understand what the ecosystem is
2. identify what they want
3. find the right path inside the ecosystem
4. start building or buying infrastructure
5. connect to the rest of the 42-site matrix

---

## Core User Outcomes

A visitor should be able to:
- learn what lippytm.ai is
- choose a direction
- discover products and platforms
- enter the right site or system
- join a membership or starter program
- request help
- start building their own infrastructure
- start using AI agents

## AI Agents Needed

## 1. Navigator Agent
Purpose:
- help users figure out where to go
- route them into the right category, site, or action

Needs:
- intent classification
- ecosystem knowledge
- cross-link routing rules

## 2. Builder Agent
Purpose:
- help users decide what to build
- recommend websites, funnels, automations, or infrastructure

Needs:
- build path suggestions
- component recommendations
- DIY vs DFY logic

## 3. Offer Agent
Purpose:
- match users with the right offers
- show starter plan, upgrades, and relevant upsells

Needs:
- pricing logic
- offer ladder rules
- audience matching rules

## 4. Content Agent
Purpose:
- generate and refine page copy, hooks, CTA text, and summaries

Needs:
- brand voice rules
- category copy templates
- ad copy template library

## 5. Sales Capture Agent
Purpose:
- optimize capture pages and recommend hook/CTA variants

Needs:
- audience hook patterns
- CTA testing logic
- conversion checklist rules

## 6. AI Agent Builder Agent
Purpose:
- explain personal AI agent systems
- help users choose or design their own agent stack

Needs:
- agent catalog
- role selection logic
- customization flow

## 7. Ecosystem Librarian Agent
Purpose:
- explain what every site, platform, and category does
- serve as the knowledge guide for the entire ecosystem

Needs:
- site directory knowledge
- docs summaries
- ecosystem glossary

## 8. Monetization Agent
Purpose:
- show users how to make money with the ecosystem
- explain subscriptions, affiliate paths, templates, services, and upgrades

Needs:
- revenue model map
- offer relationships
- entry-to-upgrade logic

## 9. Support / Troubleshooting Agent
Purpose:
- answer user issues
- handle platform questions
- point users to the right help path

Needs:
- FAQ system
- issue routing
- troubleshooting flows

## 10. Control Tower Agent
Purpose:
- connect the hub to reporting, orchestration, and future multi-site operations

Needs:
- site health summaries
- top metrics
- cross-site analytics hooks

## Closing Doctrine

`lippytm.ai` must be built first as the master portal of the ecosystem.

Its job is to orient the visitor, classify intent, show the ecosystem, present the offers, and activate the first AI agents.

Once the first site has its component list and agent architecture in place, the rest of the 42 websites can be built from the same platform logic with category-specific variations.
