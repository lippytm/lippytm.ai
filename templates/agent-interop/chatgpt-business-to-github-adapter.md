# Adapter Template — ChatGPT Business to GitHub

## Purpose

Convert creative work from ChatGPT Business into durable GitHub and Zo Computer assets.

## Input

- ChatGPT Business conversation summary
- source text or exported markdown
- campaign/product/repository destination
- desired output type

## Output

- cleaned markdown document
- GitHub path recommendation
- summary of changes
- next action checklist

## Steps

1. Paste or export the ChatGPT Business output.
2. Classify the asset: campaign, eBook, prompt, workflow, product spec, article, video script, or Zapier template.
3. Remove duplicate or confusing material.
4. Add audience, offer, CTA, revenue path, and safety notes.
5. Save to workspace.
6. Mirror into the correct GitHub repo.
7. Commit with a clear message.

## Approval gates

Ask before publishing publicly, sending externally, or making financial/funding claims.
